# Portfólio Profissional - Alesandro Matos

Portfólio desenvolvido em React para apresentar meus projetos, habilidades, experiências e trajetória na área de tecnologia.

## Sobre o projeto

Este portfólio foi criado com foco em visual moderno, interatividade e apresentação profissional. Ele possui animações, cena 3D, partículas no fundo, cursor personalizado, timeline de experiência, formulário de contato e integração com a API do GitHub para exibir projetos automaticamente.

## Tecnologias utilizadas

- React
- JavaScript
- CSS
- Three.js
- React Three Fiber
- Drei
- Framer Motion
- React Icons
- EmailJS
- GitHub API

## Funcionalidades

- Interface moderna e responsiva
- Cena 3D interativa
- Fundo com partículas animadas
- Loading screen
- Cursor personalizado
- Seção de experiência
- Timeline profissional
- Formulário de contato com EmailJS
- Projetos reais puxados automaticamente do GitHub
- Botão para baixar currículo
- Links para GitHub e LinkedIn
